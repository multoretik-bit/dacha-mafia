# DACHA

Приложение дачников: игры, которые нас сближают.

- **Главная**: логотип DACHA, календарь игр на 7 дней (мафия, волейбол, футбол) с записью в одно касание, плитки игр, значок «дачники» — все участники в стиле соцсети.
- **Профиль**: аватарка, ник, «о себе», места в рейтингах мафии, волейбола и футбола, ачивки, роли в мафии.
- **Волейбол и футбол**: даты, запись, итоги (ведущий отмечает, кто победил и кто проиграл), рейтинг за всё время и по месяцам. Ведущих спорта назначает только @tivishka. Схема — `supabase/sports.sql`.

## Мафия

- **Ведущий**: число игроков, роли (мафия, дон, комиссар, патрульный, куртизанка, доктор, маньяк или свои), раздача карт по кругу: нажал — увидел карту, нажал — закрыл и передал телефон.
- **Игрок**: блокнот стола — цвет доверия (серый / чёрный / красный), заметки про каждого, «выбыл» уводит игрока вниз, счётчик живых.
- **Новое лобби** сбрасывает игру.

- **Вход через Telegram** (бот [@dacha_gay](https://t.me/dacha_gay), мини-приложение): без регистрации, ник меняется в профиле, под ником — @username и аватарка из Telegram. Профиль со статистикой по ролям и победам, рейтинг.
- **Онлайн-раздача**: ведущий отмечает, кто играет, карта роли приходит прямо на телефон каждого, а бот присылает сообщение «Тебе пришла карта». Гости без аккаунта смотрят карту на телефоне ведущего.

Статический `index.html` без сборки + Supabase (аккаунты, база, realtime). Схема базы — `supabase/schema.sql` и `supabase/telegram.sql`, серверная функция входа и бота — `supabase/functions/tg`. Правила доступа: каждый видит только свою роль, ведущий — всю раскладку, статистика считается только по завершённым играм. Блокнот и раздача с одного телефона хранятся в браузере.
