# DACHA MAFIA

Приложение для игры в мафию с одного телефона.

- **Ведущий**: число игроков, роли (мафия, дон, комиссар, патрульный, куртизанка, доктор, маньяк или свои), раздача карт по кругу: нажал — увидел карту, нажал — закрыл и передал телефон.
- **Игрок**: блокнот стола — цвет доверия (серый / чёрный / красный), заметки про каждого, «выбыл» уводит игрока вниз, счётчик живых.
- **Новое лобби** сбрасывает игру.

Один статический файл `index.html`, без сборки. Данные хранятся в браузере (localStorage).
