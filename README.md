# DACHA MAFIA

Приложение для игры в мафию с одного телефона.

- **Ведущий**: число игроков, роли (мафия, дон, комиссар, патрульный, куртизанка, доктор, маньяк или свои), раздача карт по кругу: нажал — увидел карту, нажал — закрыл и передал телефон.
- **Игрок**: блокнот стола — цвет доверия (серый / чёрный / красный), заметки про каждого, «выбыл» уводит игрока вниз, счётчик живых.
- **Новое лобби** сбрасывает игру.

- **Аккаунты дачников**: ник и пароль без почты, профиль со статистикой по ролям и победам, рейтинг.
- **Онлайн-раздача**: ведущий отмечает, кто играет, и карта роли приходит прямо на телефон каждого. Гости без аккаунта смотрят карту на телефоне ведущего.

Статический `index.html` без сборки + Supabase (аккаунты, база, realtime). Схема базы и правила доступа — `supabase/schema.sql`: каждый видит только свою роль, ведущий — всю раскладку, статистика считается только по завершённым играм. Блокнот и раздача с одного телефона хранятся в браузере.
